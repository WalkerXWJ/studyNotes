# 1. DVWA

DVWA 是一个专为网络安全学习设计的漏洞演示 Web 应用，采用 PHP/MySQL 开发，包含多种常见 Web 漏洞的可配置实验环境。

项目官网：https://dvwa.co.uk
GitHub 仓库：https://github.com/digininja/DVWA
本次练习采用环境： Kali Linux + DVWA + Burpsite pro

## 1.1. 练习环境搭建

```bash
# kali linux install dvwa
sudo apt install dvwa -y

# start dvwa service
sudo dvwa-start
# stop dvwa service
sudo dvwa-stop
```

❓虚拟机外不能访问dvwa，可以调整虚拟机的网络连接模式如NAT 调整为 桥接

❓dvwa 虚拟机内访问正常，虚拟机外访问提示 `403 Forbidden`
