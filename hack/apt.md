# ATP（Advanced Persistent Threat 高级持续性威胁、先进持续性威胁）

## 1、APT的基础概念

**定义**：由某些人员策划，针对特定目标隐匿而持久的入侵过程。

**目的**：通常为商业目的或政治动机。

**目标**：特定的组织或国家。

**要求**：常时间内保持高隐蔽性。

**APT三要素：**

- 高级：使用复杂精密的恶意软件及技术以利用系统的漏洞。

- 长期：暗指某个外部力量会持续监控特定目标，并从其总获得数据。

- 威胁：指人为参与策划的攻击。

**说明**：个人黑客，通常不被称为APT，因为即使个人有意愿攻击特定目标，他们通常也不具备高级和长期这两个条件。

**APT的例子**：震网蠕虫，`Stuxnet`蠕虫病毒（超级工厂病毒），又名`震网`是世界上首个针对工控系统编写的破坏性病毒，能利用window系统和西门子SIMATIC WinCC系统的7个漏洞进行攻击。特别是针对西门子公司的SIMATIC WinCC监控与数据采集 (SCADA) 系统进行攻击，由于该系统在我国的多个重要行业应用广泛，被用来进行钢铁、电力、能源、化工等重要行业的人机交互与监控。传播途径：该病毒主要通过U盘和局域网进行传播。历史“贡献”：曾造成伊朗核电站推迟发电。2010-09-25，进入中国。2010年6月，白俄罗斯网络安全公司VirusBlokAda技术人员在伊朗客户电脑中发现了一种新的蠕虫病毒，根据代码中出现的特征字“stux”将其命名为“Stuxnet”。

**APT术语：**

- 通常指：政府、公司、政治活跃分子长期而复杂的黑客攻击；

- 也指代：发起APT攻击的幕后团体；

- 逐渐变更为：只用于指代计算黑客入侵。

**可能受到APT攻击的目标**：掌握大量个人信息组织、或具有特殊经济价值、科技价值、政治价值的组织，如教育机构、金融机构、能源公司、军工企业、涉密单位、航空单位等。

## 2、APT的特点

Bodmer、Kilger、Carpenter和Jones的研究将APT的标准定义如下：

- 目标：威胁的最终目标，即你的对手；

- 时间：即调查、入侵所花的时间；

- 资源：所涉及的知识和工具；

- 风险承受能力：威胁能在多大程度上不被发觉；

- 技能与方法：所使用的工具及技术；

- 行动：威胁中所采取的具体行动；

- 攻击源头：攻击来源的数量；

- 牵涉数量：牵涉到多少部门或外部系统，多少人的系统具体不同的重要性。

## 3、APT生命周期

APT的幕后黑手会对组织团体的金融财产、知识产权及名誉造成持续变化的威胁，其过程如下：

1. 因特定目标而盯上某个组织；

2. 试图入侵到其环境中去（如发送钓鱼邮件）；

3. 利用入侵的系统访问目标网络；

4. 部署实现攻击目标所用的工具；

5. 隐匿踪迹以便将来访问。

2013年，美国网络安全公司麦迪安（Mandiant）发布了关于2004至2013年间疑似来源于中国的APT攻击的研究结果，其中的生命周期与上述相似：

- 初始入侵：使用社会工程学、钓鱼攻击、零日漏洞，通过邮件进行；在受害车常去访问的网站上植入恶意软件（挂马）也是一种常用的手段（水坑攻击）。

- 站稳脚跟：在受害者的网络中植入远程访问工具，打开网络后门，实现隐蔽访问。

- 提升权限：通过利用漏洞及破解密码，获得受害者计算机管理员权限，并尝试获得windows域管理员权限。

- 内部勘查：收集周遭设施、安全信任关系、域结构信息。

- 横向发展：将控制权扩展到其他工作站、服务器及设施，收集数据。

- 保持现状：确保继续掌控之前获取到的访问权限和凭据。

- 任务完成：从受害者的网络中传出窃取到的数据。
