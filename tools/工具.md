### axel下载工具
Axel 是一个轻量级、多线程、支持断点续传的命令行下载加速器
- 基本语法
```bash
axel [选项] <下载URL>
```
- 使用默认的 4 个连接下载文件。下载的文件会保存在当前目录。
```bash
axel https://example.com/large-file.zip
```
- 指定线程数加速下载
```bash
axel -n 10 https://example.com/large-file.zip
```
- 指定保存目录和文件名
使用 12 个连接下载文件，并将其保存到 `/home/user/Downloads`目录，文件名为 `myfile.iso`。
```bash
axel -n 12 -o /home/user/Downloads/myfile.iso https://example.com/linux.iso
```
-  限速下载
使用 8 个连接下载，但将速度限制在 500KB/s (500 * 1024 = 512000 Bytes/s)，避免占满带宽。
```bash
axel -n 8 -s 512000 https://example.com/large-file.tar.gz
```
- 静默模式（用于脚本）
使用简洁输出，不显示进度条，非常适合在自动化脚本中使用。
```bash
axel -a -n 10 https://example.com/large-file.zip
```
- 处理 HTTPS 证书问题
如果下载 HTTPS 链接时遇到证书错误，可以跳过检查。
```
axel -k https://example.com/insecure-file.zip
```
- 添加 HTTP 头信息
```bash
axel -H "User-Agent: Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36" https://example.com/file.bin
```
