# 金融反欺诈

反欺诈从业者工作职责：在防止和减少欺诈的过程中，权衡商业中最主要的三类目标，增加收入、降低成本、减少损失，使公司利润最大化。

反欺诈工作视角：让相关部门感受到欺诈影响了他们的核心利益，并帮助他们找到阻止欺诈的最佳方案。

- 财务部门：重点在盈利能力，意味着关注交易损失、管理成本和收入。----需要解释一切影响盈利的因素。

- 运营部门：重点在行政费用管理，意味着关注人员编制相关问题----需要解释人力资源、人员编制、销售费用、交易成本是否增加。

- 销售部门：重点在营销转化率，即确保每一个可能的订单成交----需要解释你的策略不会影响销售，不会侵犯正常的客户。

## 术语：

- **反欺诈从业者（fraud practitioner）**：为企业积极参与定义、管理和监督进行反欺诈实践的人。

- **触点（touch point）**：客户交互或交易的所有接触点，即客户使用产品、服务时与公司、系统进行的各种交互。

- **信用卡（Credit Card）**：是指记录持卡人账户相关信息，具备银行授信额度和透支功能，并为持卡人提供相关银行服务的各类介质。

- **自动清算（ACH）**：是批量处理大额贷记和借记交易的电子支付网络，是美国处理银行付款的主要系统。

- **聚合支付**（payment aggregators）：又称平台商（master merchants），一种聚合支付方式，是服务商的一种，其他电商商家依托它们完成交易。

- **平台商关系**：聚合服务供应商代表商家收取款项的关系，其中商家的账户属于聚合服务供应商，商户通过合同授权服务提供商代为首款，并保障服务商会将款项归还。

- **方案**：一组实体工具及其特性和响应技术，表示欺诈管理中的实体部分。

- **策略**：一组具有逻辑支撑的技术或信号，用于支持和促进商业活动，体现欺诈管理的内在逻辑。

- **工具**：在反欺诈方案中使用的个人申请、软件即服务（SaaS）或数据源。

- **特点**：某些工具将数据转化为可用信号所展现的能力。

- **信号**：技术本身或衍生的反馈，例如信用卡地址验证服务，其返回结果为“True”。

- **技术**：通过业务流程、经验、政策和逻辑规则来评估、预测或确认可能结果的方法，如验证、规则引擎、电话认证及模拟。

- **事件**：与客户互动流程直接相关的工作流程部分，如购买、退货、账户变更、退款和投诉。

- **结果**：欺诈管理决策的最终执行建议，例如接受、合规或拒绝等。

- **流程与控制**：针对特定交易特点的选择过程，例如对下单地址与配送地址不一致的订单或隔夜运送订单进行进一步审核。

## 核心观点：

1. 将风控反欺诈的提升至战略地位，植入到公司的日常运营体系中。

2. 考虑主动投资反欺诈技术手段、防控工具、和策略，达到预防效果，减少欺诈带来的风险和资本损失。

3. 风险控制部门实现由纯成本部门到利润中心的转变，对外实现技术能力和系统能力的输出，惠及社会。

4. 支付的本质是货币转移，风险管理是金融业可以持续发展的根本。

5. 有效的反欺诈策略制定，需要多部门的投入与帮助，客服、销售、信息技术、财务、法律部门等。

## 金融反欺诈的威胁

1. 传统个体欺诈已演变为有组织、有规模的群体欺诈和关联风险。

2. 传统反欺诈停留在识别一度风险的简单规则，无法控制二度、三度和网络全局风险。

## 支付介绍

### 支付的形式

两者区别在于是否客户是否将实体卡片交给商家来完成支付。

1. 面对面支付（有卡交易）

2. 非面对面支付（无卡交易）

### 支付的框架

服务供应商主要采取的8中服务方式：

1. 信用卡支付（Credit card payment）

2. 自动清算（ACH，Automated Clearing House）和银行付款（bank payment）

3. 聚合支付（payment aggregators）

4. 信用期限服务供应商（Credit-term providers）

5. 现金替代服务服务供应商（Cash-alternative providers）

6. 广告供应商（Advertising providers）

7. 移动支付服务供应商（Mobile payment providers）

8. 账单支付服务供应商（Invoicing payment providers）

用户选择支付方式的根本驱动因素：

- 成本: 在中国，许多支付方式都提供较低的手续费或优惠活动，消费者通常会选择成本更低的支付方式。

- 安全/信任: 消费者对支付安全性非常关注，尤其是在电商交易中。支付宝和微信支付等知名平台通过建立信任机制吸引用户。

- 便利性: 移动支付的便捷性是消费者选择的一个重要因素，尤其是在城市中，用户更倾向于快速、无缝的支付体验。

公司在选择不同支付方式使会产生不同的效果，在选择时需要考虑地域支持、客户偏好、客户基础、投资回报。

### 自动清算和银行付款

自动清算：

- 自动清算的“主动”支付方式：消费者将资金存放在支付方式供应商网络账户，供应通过安全方式将资金转给商家。

- 自动清算的“被动”支付方式：供应商储存账户信息，当消费者进行消费时，资金会从消费者的账户中提取出来并转给商家。

自动清算所服务可以限制欺诈和身份盗取，这将吸引谨慎的个人成为用户。

银行付款：

- **银行转账**：用户可以通过网银、手机银行等渠道进行实时转账，适用于个人和企业之间的资金流动。

- **第三方支付平台**：支付宝、微信支付等平台提供便捷的支付解决方案，用户可以通过扫描二维码或者直接输入金额进行支付。

- **快捷支付：**银行与第三方支付平台合作，用户通过绑定银行卡，可以实现一键支付，极大方便了线上购物和线下消费。

- **POS机支付**：传统商户仍然广泛使用POS机进行刷卡支付，结合电子支付方式，形成了线上线下相结合的支付环境。

- **电子钱包**：用户可以通过银行提供的电子钱包服务管理资金，进行消费和转账。

低费用的代价是不能杜绝退款欺诈和商家的坏账风险。

### 聚合支付

主要聚合支付服务商：

1. **支付宝**：作为中国最大的第三方支付平台之一，支付宝提供了聚合支付服务，支持多种支付方式的整合。

2. **微信支付**：与支付宝并驾齐驱，微信支付也提供聚合支付服务，便于商家在一个平台上接受多种支付方式。

3. **云闪付**：由中国银联推出，支持多种银行卡和支付方式，提供聚合支付解决方案。

4. **拉卡拉**：提供包括聚合支付在内的多种支付服务，支持商户通过其平台接入多个支付渠道。

5. **富友支付**：提供聚合支付解决方案，帮助商户整合各类支付渠道，提升交易效率。

聚合支付的服务形式：

1. **二维码支付**：商家生成一个二维码，消费者可以通过支付宝、微信支付等多种方式扫码支付。

2. **POS机聚合支付**：通过智能POS机器，商家可以同时接受多种支付方式，如银行卡、支付宝、微信支付等。

3. **移动支付**：商家通过手机APP提供聚合支付功能，让消费者可以选择不同的支付方式进行支付。

4. **在线支付**：电商平台通过聚合支付接口，允许消费者在结算时选择多种支付方式。

5. **自动扣款**：针对订阅服务或定期支付，聚合支付可以实现用户授权后自动扣款，简化支付流程。

### 信用期限服务供应商

主要信用期限服务商：

1. **支付宝**：旗下的花呗服务提供了消费信贷，用户可以先消费后还款，选择分期付款。

2. **京东**：京东白条作为其信用服务，允许用户在京东平台购物时选择先消费后付款或分期还款。

3. **微众银行**：推出的“微粒贷”服务，用户可以根据自身信用情况获得贷款额度，进行消费或提现。

4. **网商银行**：提供的“小微贷款”服务，主要针对小微企业及个人，支持灵活的贷款期限和额度。

5. **苏宁**：苏宁金融推出的信用贷款产品，用户可以在苏宁平台上进行消费或提现，享受信用额度。

信用期限服务的服务形式：

1. **消费信贷**：用户可以在购物时使用信用额度，享受先消费后付款的便利，如花呗和京东白条。

2. **分期付款**：用户在购物时选择将消费金额分摊到多个账期进行还款，降低一次性支付压力。

3. **现金贷款**：通过信用额度，用户可以申请现金贷款，用于个人消费或紧急资金需求。

4. **信用卡**：各大银行发行的信用卡，用户可以在限额内消费，享受一定的免息期。

5. **信用担保服务**：一些平台提供的信用担保，用户可在商家或平台的支持下获得贷款或信用额度，确保交易的安全性。

### 现金替代服务服务供应商

现金替代支付方式并非新概念，是一种由第三者保存附带盖章的契约，如支票、储蓄账户、汇票等。

国内主要的现金替代服务商：

1. **支付宝**：提供多种支付方式，包括余额支付、花呗、信用卡等，广泛用于线上和线下消费。

2. **微信支付**：作为微信的一部分，提供便捷的支付服务，用户可以使用微信零钱进行消费。

3. **京东支付**：京东平台自有的支付工具，支持购物卡、白条等多种支付方式。

4. **银联支付**：通过银联二维码支付等方式，用户可以实现便捷的现金替代支付。

现金替代的服务形式：

1. **电子钱包**：如支付宝、微信支付等，用户可以将现金充值到电子钱包中进行支付。

2. **虚拟卡**：如京东购物卡、各类品牌的礼品卡和会员卡，用户可以用这些卡片进行消费。

3. **移动支付**：通过手机APP进行扫码支付、NFC支付等，减少了现金交易的需求。

4. **在线支付**：通过网银、第三方支付平台等方式进行购物支付，避免了现金交易。

### 广告替代支付

主要广告替代支付服务商：

1. **支付宝**：除了传统的支付功能外，支付宝还推出了基于消费的广告投放和推广服务，商家可以通过支付宝进行品牌宣传和产品推广。

2. **微信支付**：作为微信生态的一部分，微信支付结合了社交网络的特点，支持商家通过朋友圈和公众号进行广告宣传，吸引用户进行消费。

3. **今日头条**：字节跳动旗下的平台，通过信息流广告等形式为商家提供广告投放服务，吸引用户点击并实现消费。

4. **抖音**：作为短视频平台，抖音不仅提供支付功能，还允许商家通过视频内容进行品牌宣传和产品推广。

5. **快手**：类似于抖音，快手也允许商家在平台上投放广告，并通过直播等形式进行产品销售。

广告替代支付的服务形式：

1. **信息流广告**：在各类APP和网站上投放的广告，用户通过点击广告可以直接进行购买或了解更多信息。

2. **社交广告**：通过社交媒体平台（如微信、微博等）进行的广告投放，利用用户的社交关系进行传播。

3. **视频广告**：在短视频平台（如抖音、快手）投放的广告，用户观看视频时可以直接点击链接进行购买。

4. **直播带货**：商家或网红通过直播形式进行产品介绍和销售，促使用户直接进行购买，形成广告与消费的结合。

5. **搜索引擎广告**：通过百度等搜索引擎投放的竞价广告，当用户搜索相关关键词时展示，并引导用户进行购买。

### 移动支付服务供应商

主要移动支付服务商：

1. **支付宝**：作为中国最大的移动支付平台之一，支付宝提供多种支付功能，包括扫码支付、转账、账单支付等。

2. **微信支付**：依托微信生态系统，微信支付为用户提供便捷的移动支付服务，包括社交支付、线下扫码支付等。

3. **银联云闪付**：中国银联推出的移动支付服务，支持多种银行卡支付，提供便捷的扫码和NFC支付功能。

4. **京东支付**：京东旗下的移动支付服务，支持在京东平台及线下商户的支付功能。

5. **苏宁支付**：苏宁推出的移动支付解决方案，支持在苏宁平台及其合作商户的支付。

移动支付服务的服务形式：

1. **扫码支付**：用户通过手机扫描商家提供的二维码进行支付，方便快捷。

2. **NFC支付**：通过近场通信技术，用户只需将手机靠近支持NFC的POS机即可完成支付，无需扫描二维码。

3. **转账支付**：用户之间可以通过移动支付平台进行即时转账，方便好友之间的资金往来。

4. **在线支付**：在电商平台或App内完成购买时，用户可以选择使用移动支付进行结算。

5. **账单支付**：用户可以通过移动支付平台缴纳水电费、电话费、信用卡账单等各类生活费用。

6. **信用支付**：一些平台提供的消费信贷服务，用户可以先消费后付款，享受一定的信用额度。

### 账单支付服务供应商

主要账单支付服务供应商：

1. **支付宝**：提供多种生活缴费服务，包括水电费、燃气费、手机话费等账单支付功能。

2. **微信支付**：通过微信的生活服务功能，支持多种账单的支付，如交通罚款、信用卡账单等。

3. **云闪付**：中国银联推出的支付工具，支持各种账单的支付，用户可以通过该平台缴纳各类费用。

4. **各大银行APP**：例如工商银行、建设银行、农业银行等，均提供账单支付服务，用户可以通过银行的移动应用程序进行各项费用的支付。

5. **第三方支付平台**：如拉卡拉、富友支付等，也提供账单支付服务，支持多种生活费用的缴纳。

账单支付服务的服务形式：

1. **水电燃气费支付**：用户可以通过支付平台直接缴纳每月的水费、电费和燃气费。

2. **手机话费充值**：通过各大支付平台，用户可以方便地为自己的手机号码充值。

3. **信用卡还款**：用户可以在支付平台上直接选择对应银行的信用卡进行还款。

4. **交通罚款支付**：一些支付平台支持直接缴纳交通罚款，方便用户处理罚款事务。

5. **物业费缴纳**：部分地区的物业管理公司与支付平台合作，用户可以通过移动支付方式缴纳物业管理费用。

6. **税费缴纳**：部分城市提供在线税费缴纳服务，用户可以通过各类支付工具完成相关税费的缴纳。
