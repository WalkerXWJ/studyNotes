### Git Desktop
### ​**英语原文**​

```markdown
Error  

! Unable to pull when changes are present on your branch. The following files would be overwritten:  

.obsidian/workspace.json  

You can stash your changes now and recover them afterwards.  

Close  
Stash Changes and Continue  
```

---

### ​**中文翻译**​


```markdown
错误  

! 当您的分支存在更改时，无法拉取。以下文件将被覆盖：  

.obsidian/workspace.json  

您可以暂存当前更改，稍后恢复它们。  

关闭  
暂存更改并继续  
```

---

### ​**单词解释（含音标）​**​

|单词/短语|音标|解释|
|---|---|---|
|​**Error**​|/ˈerər/|错误，表示操作失败或出现问题。|
|​**Unable to pull**​|/ʌnˈeɪbl tu pʊl/|无法拉取（Git 术语，指无法从远程仓库同步最新代码）。|
|​**changes are present**​|/ˈtʃeɪndʒɪz ɑr ˈprɛzənt/|存在未提交的更改（如修改、新增或删除文件）。|
|​**branch**​|/bræntʃ/|Git 分支，代码的独立开发线。|
|​**overwritten**​|/ˌoʊvərˈrɪtən/|被覆盖，指文件会被远程版本替换。|
|​**stash**​|/stæʃ/|Git 暂存功能，临时保存未提交的更改。|
|​**recover**​|/rɪˈkʌvər/|恢复，此处指重新应用暂存的更改。|
|​**Close**​|/kloʊz/|关闭当前窗口（不采取任何操作）。|
|​**Stash Changes and Continue**​|/stæʃ ˈtʃeɪndʒɪz ənd kənˈtɪnju/|暂存更改并继续拉取操作。|
