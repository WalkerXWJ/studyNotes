### AI 音乐生成工具 SongGen

项目地址：https://github.com/LiuZH-19/SongGen

```bash
# 1. 安装环境和依赖项
git clone https://github.com/LiuZH-19/SongGen.git
cd SongGen
# We recommend using conda to create a new environment.
conda create -n songgen_env python=3.9.18 
conda activate songgen_env
# Install CUDA >= 11.8 and PyTorch, e.g.,
# pip install torch==2.3.0 torchvision==0.18.0 torchaudio==2.3.0 --index-url https://download.pytorch.org/whl/cu118
# ⬆️ 官方的命令在mac上安装报错 ⬇️ 安装cpu版
pip3 install torch==2.3.0 torchvision==0.18.0 torchaudio==2.3.0 --index-url https://download.pytorch.org/whl/cpu
pip install flash-attn==2.6.1 --no-build-isolation
```
